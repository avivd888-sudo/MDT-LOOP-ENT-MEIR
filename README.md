## הפעלת הקישור הקבוע (GitHub Pages)

אחרי שהמאגר עלה (הסעיף הבא):

1. במאגר ב-GitHub: **Settings → Pages**
2. תחת **Build and deployment → Source**: לבחור **Deploy from a branch**
3. **Branch**: `main` · תיקייה: **`/docs`** → **Save**
4. אחרי דקה-שתיים הקישור `https://avivd888-sudo.github.io/MDT-LOOP-ENT-MEIR/` פעיל.

כל `push` ל-`main` מעדכן את הדף אוטומטית.

### אם משתמשים ב-GitHub Desktop (בלי שורת פקודה)

1. **File → Add local repository** → לבחור את התיקייה `MDT-LOOP-ENT-MEIR`
   (אם הוא שואל — **create a repository**).
2. **Publish repository** → השם `MDT-LOOP-ENT-MEIR` → **להוריד** את הסימון
   *Keep this code private* (Pages דורש מאגר ציבורי בחשבון חינמי) → **Publish**.
3. להמשיך בשלבי ה-Pages שלמעלה.

### עדכון האפליקציה שבקישור

אחרי שינוי בקוד:

```bash
npm install        # פעם אחת
npm run docs       # בונה מחדש את docs/app.html
```

ואז commit ו-push. (אם נוסף אייקון חדש: `npm run icons` לפני `npm run docs`.)

## מצב שימוש — המעבר מהדגמה ללוח אמיתי

לאפליקציה שני מצבים, והמעבר ביניהם נעשה מתוך **״עוד ← מצב העבודה״**.

| | הדגמה | שימוש |
|---|---|---|
| הלוח הפותח | מאגר ההדגמה | **ריק** |
| סימולציה של 20 מטופלים | יש | אין |
| כפתור איפוס | יש | אין |
| מצב מקודד | ניתן לכיבוי | **נעול על ״פעיל״** |
| לוח משותף בין צופים | יש | **אין — מקומי לדפדפן** |
| איפה נשמר | `sessionStorage`, נמחק עם הכרטיסייה | `localStorage` של אותו דפדפן |

**השער.** כדי לפתוח לוח ריק יש לרשום מספר אישור של ועדת הלסינקי ותאריכו, מספר
אישור אבטחת מידע של כללית ותאריכו, שם הרושם, ולאשר ארבעה סעיפים בנפרד: שהאישור
בידי, שאבטחת המידע אישרה את הגרסה הזאת, שמוזנים מספרי מחקר מקודדים בלבד, ושהלוח
אינו יוצא מהדפדפן. הרישום נשמר מקומית ומוצג חזרה במסך ״עוד״.

השער אינו מאמת דבר מול אף גורם — הוא הצהרה, שנשמרת כדי שיהיה תיעוד מתי ובידי מי
נפתח הלוח. זה שלט חגורת הבטיחות, לא החגורה.

**מדוע אין לוח משותף במצב שימוש.** הלוח המשותף עובד בכך שהוא כותב את המצב לתוך
ה-Artifact המפורסם ב-claude.ai. להדגמה זה בדיוק מה שצריך; למטופלים אמיתיים זה
ההפך — מידע קליני מקודד שיוצא מכללית. לכן מצב השימוש מנתק אותו. לוח משותף אמיתי
מחייב אירוח של הבנייה בתוך כללית, וזו שיחה נפרדת עם מערכות המידע.

**איפה מריצים במצב שימוש.** העדיפות היא `docs/app.html` — קובץ אחד שעובד בלי רשת,
על מחשב כללית. כתובת ציבורית (GitHub Pages או Vercel) מתאימה להדגמה ולהצגה, לא
לפיילוט.

מבנה מספר המחקר וכללי ההקצאה: `docs/materials/MDT-Loop-ENT-study-id-sop.pdf`.

## חיבור ל-Vercel (לא חובה — כתובת שנייה לאפליקציה בלבד)

2. **Import** את המאגר `MDT-LOOP-ENT-MEIR`
3. Framework Preset: **Next.js** (נבחר אוטומטית)
4. **אין** צורך במשתני סביבה — משאירים את Environment Variables ריק
5. **Deploy**

הכתובת שתתקבל תיראה כך:

```
https://mdt-loop-ent-meir.vercel.app/
```

שם המארח הזה גלובלי ב-Vercel. אם הוא כבר תפוס, Vercel יוסיף סיומת — אפשר לשנות
